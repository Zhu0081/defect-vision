## 三、B 组的关键设计（这里最容易做错）

### 3.1 为什么"同一批工件"是故意的

B 组里训练集和测试集用的是**同一批工件**（同 part_id），只是光源不同。

这**在 A 组里是绝对禁止的**（等于背题）。但 B 组是**故意**这么设计的 ——
因为 B 组要测的不是"泛化能力"，是"**光源敏感度**"。

把它固定住：工件不变、缺陷位置不变、只换光源。这样指标的变化只能归因于光源。

### 3.2 面试官一定会问"你这不是泄漏吗"

标准答法：

> "两组实验的回答对象不同。
> A 组把工件分开，测的是**跨工件泛化**，那组不能有任何泄漏。
> B 组我故意用同一批工件，因为我要隔离出单一变量 —— 光源。
> 如果 B 组也用新工件，指标一掉我就说不清是光源的问题还是工件的问题。
> 所以这两组数不能互相比较，它们回答的是两个不同的问题。"

**这个区分本身就是加分项。** 大多数人只做过 A，没想过还有 B。

### 3.3 你要报的三个数

```
A 组：跨工件 · 侧光      0.904      （已有）
B 组：跨光源 · 同工件     ???        （周六后）
Δ   ：                    ???        ← 这个数才是结论
```

⚠️ **缺陷不要重画。** 用现在这 12 张纸，原来的马克笔痕迹原地保留。
位置变了就多了一个变量。

### 4.2 顶光怎么架（今晚先试）

顶光的意思是：光源在纸的**正上方**，垂直向下照。要点：

1. 手机支架 / 书堆把**灯架高**，灯头朝下，距桌面 40–60 cm
2. 灯不要入镜（画面里不能看到灯泡本身）
3. 手机和三脚架位置**完全不动**，只换灯
4. 纸的位置**完全不动**，用胶带在桌面做个记号

> 如果灯架不稳、光斑太集中，退而求其次：用**背光**（纸下面放灯，透光拍）。
> 背光对缺件、破孔特别敏感，也是工业上的标准做法之一。效果一样有效。

### 4.3 判定这张顶光照行不行

拍完第一张，跑：

```powershell
python -c "import cv2;g=cv2.imread(r'路径',0);print('luma=%.1f'%g.mean())"
```

| 指标 | 合格线 |
|---|---|
| 纸面平均亮度 | 90 – 160 |
| 过曝像素（≥250） | < 1% |
| 缺陷肉眼可见 | 必须 |

**不合格就调灯的高度或亮度，别靠后期。**

## 七、三种可能的结论，都要能讲

| 结果 | 含义 | 怎么讲 |
|---|---|---|
| Δ < 5 个点 | 模型学的是缺陷本身，对光照鲁棒 | "侧光是主要成像方式，顶光下损失很小，说明特征是有物理意义的" |
| Δ = 20–40 点 | 模型部分依赖光照条件 | "换光源后掉了 X 个点，说明需要做光源归一化或数据增广" |
| Δ > 60 点 / 直接崩 | 模型学的是"侧光下的暗线"，不是缺陷 | "这是最有价值的负结果：它证明在单光源数据上训出来的模型不可移植，工业上必须多光源采集" |

**第三种不算失败。** 一个能说出"我知道我的模型在什么条件下会崩、为什么崩"的人，
比一个只会报漂亮数字的人可信得多。
