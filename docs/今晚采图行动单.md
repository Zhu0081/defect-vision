## 1. 材料清单：在宿舍能凑到的

| 要什么 | 去哪找 | 替代品 |
|---|---|---|
| **工件（PCB）** | 废路由器、坏遥控器、旧充电器、废旧鼠标 | 任何带元件的电路板 |
| **良品** | 同款但没破坏的另一块板 | **必须是同款**，见 §3 |

**没有的东西不要临时买。** 今晚是验证流程，不是出成品。

## 2. 缺陷怎么造（这是今晚最关键的 15 分钟）

> ⚠️ **安全第一**：划 PCB 时刀刃朝外、垫在废纸上；不要用打火机（宿舍禁火），要加热用电吹风。

### PCB 能造的 4 类

| 类型 | 怎么造 | 注意 |
|---|---|---|
| **scratch 划痕** | 美工刀尖**轻划** 3–5 条，长度 5–15mm | 别割断走线；划完立刻拍，氧化后形态会变 |
| **stain 脏污** | 铅笔芯磨粉 + 指腹抹开；或一滴咖啡晾干 | 别用会流动的液体，拍的时候会移位 |
| **missing 缺件** | 掰掉一个电容/电阻（没烙铁就用钳子夹住左右晃断） | **断口要能看见**，别整个铲平 |
| **deform 变形** | 钳子轻夹板边压出凹坑 / 掰弯一个角 | 力度小一点，裂了就没法当"变形"用了 |

### 一个必须理解的概念：**可复现**

划痕、脏污、缺件 —— 造一次，**能反复拍 5–8 个位置都不变**。
变形 —— 掰完就定型了，也能复拍。

**为什么要强调这个？** 因为同一个缺陷要在不同角度、不同光源下各拍几张。如果缺陷一碰就变形/消失，你的数据集里"同一处缺陷"长得完全不一样，标注也没法对。

### 不要造的

- ❌ 把板子烧黑一大片（整张图废，模型只会学"黑=坏"）
- ❌ 撒一把沙子在板上（这不是缺陷，是垃圾）
- ❌ 用 Photoshop 造假缺陷贴上去（光照和噪声对不上，模型会学 PS 痕迹 —— 这是**数据造假**，面试一问就穿帮）

## 3. 一条铁律：良品必须和不良品同源

**错误做法**：良品用崭新的板，不良品用旧板划一刀。

模型会学到一个捷径：**"旧的/脏的 = 不良"**。上线后遇到一块落灰的良品，直接误杀。

**正确做法**：从**同一批**废旧板里挑 —— 挑两块外观最接近的，一块保持原样当良品，另一块造缺陷当不良品。

> 这条在面试里能讲成一个很好的故事：**"我一开始良品用了新板，验证集 F1 很高，但换了一批旧板后过杀率飙升 —— 因为模型学的是『新旧』不是『缺陷』。"**

## 4. 5 分钟搭台

```
        台灯（垫两本书，灯头压低）
              ＼
               ＼  20–30° 掠射
                ＼
    ┌───────────────────────┐
    │                       │   ← 书堆当支架，摄像头压在书上
    │      [ A4 白纸 ]       │      镜头距工件 25–35cm
    │       [ 工件 ]         │
    └───────────────────────┘
```

三条硬要求：

1. **关房灯、拉窗帘** —— 只用台灯一个光源。混色温会让白平衡漂移。
2. **相机不手持** —— 压在书堆上。手持拍 30 张，30 张的视角都不一样，等于 30 个噪声。
3. **工件占画面宽度 70–80%** —— 太远模型看不清缺陷，太近边缘切掉。

## 5. 开拍（10 分钟）

```powershell
cd F:\defect-vision
python src\capture\grab.py --source 0 --auto --category pcb --part 001 --light side
```

**参数一条条的意思：**

| 参数 | 你现在该填什么 |
|---|---|
| `--source 0` | 笔记本摄像头（手机的话填 `"http://IP:8080/video"`） |
| `--auto` | 全自动曝光（这台机器的摄像头手动曝光坏了，必须用这个） |
| `--category pcb` | 今晚只做 PCB |
| `--part 001` | **一个物理工件一个号**，换了板子就换成 002 |
| `--light side` | 侧光。今晚先拍 side，再拍 top |

### 每按一次 SPACE 之前，做两个动作

- **平移 ±10%**（左右挪一点）
- **旋转 ±10°**（转一点角度）

**为什么？** 让模型学"缺陷长什么样"，而不是"缺陷在画面第几像素"。总在同一个位置拍，模型就记住位置了。

### 切光源

按 `n` → 重新输入类别/件号/光源，把 `side` 改成 `top` 继续拍。

## 7. 收工自检（3 分钟）

```powershell
$rows = Import-Csv F:\defect-vision\data\captured\metadata.csv

"总张数      = $($rows.Count)"
"亮度异常    = $(@($rows | Where-Object { $_.luma_ok -ne '1' }).Count)"
"清晰度中位数 = $((@($rows | ForEach-Object { [double]$_.sharpness }) | Sort-Object)[[int]($rows.Count/2)])"

$rows | Group-Object light | ForEach-Object {
  $l = @($_.Group | ForEach-Object { [double]$_.luma_mean })
  $avg = ($l | Measure-Object -Average).Average
  "$($_.Name)`t张数=$($l.Count)`t平均亮度=$([math]::Round($avg,1))"
}
```

**三个数字看什么：**

| 指标 | 合格线 | 不合格说明 |
|---|---|---|
| `luma_ok` 不等于 1 的比例 | **< 10%** | 台灯在晃 / 相机在自动调亮度 |
| 同一光源内亮度标准差 | **< 5** | 环境光在变（窗帘没拉、有人开灯） |
| sharpness 中位数 | **> 100** | 对焦没对上 / 距离太远 |

## 8. 拍完立刻做的一件事（2 分钟）

**随便挑 3 张，用图片查看器放大到 200%，问自己：**

> **"如果我是一个没见过这块板的人，我能一眼看出缺陷在哪吗？"**

- 能 → 数据可用，继续
- 不能 → **模型也学不会**。要么重拍，要么换缺陷造法。

这一步 90% 的人会跳过，然后在 W4 疑惑"为什么模型精度上不去"。

## 附：常见翻车

| 现象 | 原因 | 处理 |
|---|---|---|
| 照片一片白 | 工件反光/背景太亮 | 换深色背景，台灯挪到侧面 |
| 划痕拍不出来 | 侧光角度太平（正对工件） | 灯头压到 20–30°，让光**掠**过表面 |
| `!! BLURRY` 一直闪 | 画面里没工件（对着空白背景） | 把工件放进画面再按 `f` |
| luma 一直在 180+ | 台灯太近 | 灯挪远 20cm，或用纸挡一层柔光 |
| 拍出来偏黄 | 白平衡漂了 | 用 `--auto` 让相机自己追；实在不行换手机 |
