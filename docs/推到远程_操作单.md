# ⚠️ 先看：GitHub 打不开怎么办

2026-10-28 晚实测（本机）：

| 目标 | 结果 |
|---|---|
| `github.com` 首页 / 注册页 | ❌ 8 个官方 IP **全部 TLS 握手被卡**，15 秒超时 |
| `github.githubassets.com`（CDN） | ✅ 0.45 秒 |
| `gitee.com` | ✅ 0.6 秒，SSH 22 端口可达 |

**这不是你的网络问题**，也不是 DNS 被污染（域名解析出的是正确的 GitHub IP，是连接阶段的 TLS 被掐断）。改 DNS、改 hosts 都**没用**。

三条对策，按有效程度排：

1. **手机开热点，笔记本连热点** —— 换出口，多数情况下能通。最有效。
2. **换个时间再试** —— GitHub 在国内是时好时坏，白天有时反而通。
3. **先做 Gitee，GitHub 以后补** —— 下面的 Part 2 现在就能跑完，不阻塞。

> 两边都推的好处就是：哪个通先用哪个，另一个随时补。

## 第 0 步：复制你的公钥

打开 PowerShell，跑：

```powershell
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
```

会输出**一整行**，长这样（你的和这个不一样）：

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEeVNHcRJDUqKtRfMqjIB9cga6MtdyTeBriw9bLbPIt9 defect-vision
```

**整行复制，一个字符都不能少，开头必须是 `ssh-ed25519`。**

# 第一部分：GitHub（约 15 分钟）

## 1. 注册

打开 <https://github.com/signup>

依次填：

| 填什么 | 建议 |
|---|---|
| Email | 你的常用邮箱（能收验证码的） |
| Password | 至少 15 位，或 8 位含数字+小写 |
| Username | **这就是你简历上的链接**，用 `zhuzhenghao` 或 `zhenghao-zhu`，别用 `asdf123` |
| 邮箱验证码 | 收邮件填 6 位码 |

> 网络慢就打不开，多重试几次，或者换个时间。GitHub 在国内时快时慢。

## 2. 贴公钥

点右上角头像 → **Settings** → 左侧 **SSH and GPG keys** → 绿色按钮 **New SSH key**

| 字段 | 填 |
|---|---|
| Title | `宿舍笔记本` |
| Key type | `Authentication Key`（默认就是） |
| Key | **粘贴第 0 步那一整行** |

点 **Add SSH key**。成功后会看到这条 key 出现在列表里。

## 3. 建空仓库

打开 <https://github.com/new>

| 字段 | 填 |
|---|---|
| Repository name | `defect-vision` |
| Description | `工业表面缺陷视觉检测端到端 Demo：YOLO11n-seg + ONNX Runtime + FastAPI + PostgreSQL` |
| Public / Private | **选 Public** |
| Add a README file | ❌ **不要勾** |
| Add .gitignore | ❌ **不要选** |
| Choose a license | 不选 |

> **为什么 Public**：仓库里没有原始照片（`data/` 已被 `.gitignore` 排除），只有代码、文档和 4 张报告图，不涉密。Public 才能让 HR 直接点开看。
> **为什么什么都不要勾**：本地已经有 README 和 .gitignore 了，远程再建一份会冲突。

点 **Create repository**。

## 4. 推送

页面上会出现一串命令，**不要照抄**，用下面这两条：

```powershell
cd F:\defect-vision
git remote add origin git@github.com:你的用户名/defect-vision.git
git push -u origin main
```

把 `你的用户名` 换成第 1 步注册的那个（比如 `zhuzhenghao`）。

第一次推会问：

```
The authenticity of host 'github.com' can't be established.
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

输入 `yes` 回车。

推送成功会看到：

```
Enumerating objects: 53, done.
Writing objects: 100% (53/53), 2.90 MiB
branch 'main' set up to track 'origin/main'.
```

## 5. 验证

```powershell
ssh -T git@github.com
```

出现 `Hi 你的用户名! You've successfully authenticated` 就对了。

再打开 `https://github.com/你的用户名/defect-vision`，应该能看到 README 和架构图。

# 第二部分：Gitee 码云（约 10 分钟）

## 1. 注册

<https://gitee.com/register> —— 手机号或邮箱都行，国内不用等。

> ⚠️ 注意是 `/register`，不是 `/signup`。`gitee.com/signup` 会返回 405 白屏（实测）。

## 2. 贴公钥

右上角头像 → **设置** → 左侧 **安全设置 → SSH 公钥** → 填标题（`宿舍笔记本`）+ 粘贴公钥 → **确定**。

## 3. 建仓库

右上角 **+** → **新建仓库**

| 字段 | 填 |
|---|---|
| 仓库名称 | `defect-vision` |
| 是否开源 | **公开** |
| 初始化仓库 | ❌ 不勾（不要任何初始化文件） |

## 4. 推送（第二条 remote）

```powershell
cd F:\defect-vision
git remote add gitee git@gitee.com:你的用户名/defect-vision.git
git push -u gitee main
```

## 5. 以后两个一起推

```powershell
git push origin main
git push gitee main
```

或者一条命令推两个：

```powershell
git remote set-url --add --push origin git@github.com:你的用户名/defect-vision.git
git remote set-url --add --push origin git@gitee.com:你的用户名/defect-vision.git
```

之后 `git push` 就一次推两边。

# 以后每次改完代码

只有三条命令，**别省**：

```powershell
cd F:\defect-vision
git add -A
git commit -m "一句话说清这次改了什么"
git push
```

> `commit -m` 里写**改了什么**，不要写 "update"、"fix"。三个月后你自己回来看 commit 记录，就是一份项目日志——面试让你讲项目演进时直接照着讲。

# 常见报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `Permission denied (publickey)` | 公钥没贴上去，或贴错了 | 重新复制 `id_ed25519.pub` 整行；确认贴到 **SSH keys** 而不是 GPG keys |
| `Repository not found` | 用户名写错，或仓库名写错 | 去网页复制红框里那个地址，别手打 |
| `error: remote origin already exists` | 已经加过 remote 了 | `git remote set-url origin git@github.com:用户名/defect-vision.git` |
| `failed to push some refs` / `Updates were rejected` | 远程仓库里已经有文件（多半是建仓库时勾了 README） | 先在 GitHub 网页删掉那个仓库，重建时什么都不要勾 |
| `Connection timed out` (22 端口) | 公司/学校网络封了 22 | 在 `C:\Users\24159\.ssh\config` 里加三行：`Host github.com` / `HostName ssh.github.com` / `Port 443` |
| `Host key verification failed` | known_hosts 对不上 | `ssh-keygen -R github.com` 后重试 |
| `LF will be replaced by CRLF` | 换行符警告，**不是错误** | 忽略 |
