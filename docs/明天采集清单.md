## 二、每个工件拍 5 张

```
3 张良品 + 2 张缺陷
```

### 拍摄铁律（照做，别自由发挥）

1. 深色布料铺底，纸放在布上
2. 手机**正上方俯拍**，纸占画面 70–80%
3. 每张之间：**平移 ±10%、旋转 ±10°**
4. 关房间大灯，只用台灯（**同一盏，位置不变**）
5. 缺陷要**放大到 100% 肉眼清楚可见**才拍

### 造缺陷四选一（一个工件只造一种）

| 类型 | 造法 | 存到 |
|---|---|---|
| `scratch` 划痕 | 圆珠笔尖/钥匙轻轻划 2–4 道 | p00X |
| `stain` 脏污 | 手指抹铅笔灰 / 一滴油 / 咖啡渍 | p00X |
| `missing` 缺件 | 撕一个小角、挖一个小洞 | p00X |
| `deform` 变形 | 折一个角、揉皱一小片 | p00X |
