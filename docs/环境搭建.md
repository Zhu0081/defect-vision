## 1. 现状检查：你现在缺什么

在 PowerShell 里跑：

```powershell
python --version
```

**如果你看到的是一行空白、或者弹出微软商店**，说明你机器上**没有真正的 Python**，只有 Windows 自带的占位程序。必须先装。

（我在这台机器上检查过：`python` 指向的是 `WindowsApps\python.exe`，就是那个占位程序。）

---

## 2. 装 Python（Windows 侧，约 10 分钟）

1. 打开 https://www.python.org/downloads/windows/
2. 下载 **Python 3.11.x** 的 **Windows installer (64-bit)**
   - ✅ 用 3.11，别用 3.13。3.13 太新，opencv / onnxruntime 的预编译包还没跟上。
   - ✅ 也先别用微软商店版，坑多。
3. 运行安装包，**第一屏一定要勾上**：

   ```
   ☑ Add python.exe to PATH
   ```

   这是新手第一大坑。不勾，后面每次都要写全路径。

4. 可选勾 "Install for all users"（推荐，省权限麻烦），一路 Next 装完。
5. **关掉所有 PowerShell 窗口，重新开一个**（老窗口不会刷新 PATH），然后验证：

```powershell
python --version
# 期望输出：Python 3.11.x
```

### 如果验证时还是弹微软商店

说明 Windows 把 `python` 这个名字劫持给了商店。修法：

> 设置 → 应用 → 高级应用设置 → 应用执行别名
> 把 **`python.exe`** 和 **`python3.exe`** 两个开关都**关掉**

关掉后重开 PowerShell 再试。

## 5. 跑起来（三步）

**所有命令都在项目根目录 `F:\defect-vision` 下执行。** 因为脚本写的相对路径 `data/captured/...` 是相对「当前所在目录」的——不在根目录跑，图会存到别的地方去。

```powershell
# 第 1 步：看有哪些摄像头
python src\capture\grab.py --list-cameras

# 第 2 步：调曝光对焦（不采图）
python src\capture\grab.py --source 0 --calibrate

# 第 3 步：正式采
python src\capture\grab.py --source 0 --category pcb --part 001 --light top --exposure -5
```

> `--exposure -5` 里的数字是第 2 步调出来的值，不同相机完全不同，别照抄。

**怎么在目录里直接打开 PowerShell：**
在文件资源管理器里进入 `F:\defect-vision` → 地址栏输入 `powershell` 回车；或按住 `Shift` 右键空白处 →「在此处打开 PowerShell 窗口」。

## 6. 报错速查

| 报错 | 原因 | 修法 |
|---|---|---|
| `python` 弹微软商店 | 系统占位程序 | 见第 2 节最后，关掉应用执行别名 |
| `ModuleNotFoundError: cv2` | 装到别的 Python 里了 | 用 `python -m pip install opencv-python`（带 `-m` 确保装进当前解释器） |
| `打不开视频源：0` | 摄像头被占用或没权限 | 关掉腾讯会议/Teams/浏览器；设置 → 隐私 → 相机 → 允许桌面应用访问 |
| 画面很暗 / 很亮，显示 `LUMA DRIFT` | 曝光或台灯变了 | 重跑 `--calibrate` 定好曝光，采图期间不要动台灯的亮度旋钮 |
| 一直 `!! BLURRY` | 距离太近或没对焦 | 退到 25–35cm，按 `f` 自动对焦一次 |
| `grab.py 无法将"..."识别为 cmdlet` | 没在项目根目录 | 先 `cd F:\defect-vision` |
| 中文显示成乱码 | 控制台编码 | 已经是 UTF-8 输出；仍有问题跑 `chcp 65001` |

## 7. WSL2 部分（已装好 — 2026-10-27 实测）

采图阶段**完全不需要 WSL**。W3 跑训练时才用 —— 好消息是**已经装好了，不用动手**：

| 项目 | 实测值 |
|---|---|
| WSL 版本 | 3.0.3.0 |
| 内核 | 6.18.54.1-microsoft-standard-WSL2 |
| 发行版 | **Ubuntu 22.04.1 LTS**（名字就叫 `Ubuntu`，Version 2） |
| Python | 3.10.6（系统自带） |
| 资源 | 20 核 / 7 GB 内存 / 955 GB 可用 |

### 确认命令

```powershell
wsl --version
wsl -l -v                     # 看到 Ubuntu / Stopped 或 Running / 2 就对了
wsl -d Ubuntu -- python3 --version
```

### 进 Ubuntu

```powershell
wsl -d Ubuntu                 # 退出用 exit
```

```bash
cd /mnt/f/defect-vision       # F: 盘在 WSL 里是 /mnt/f
```

### 首次准备环境（W3 才做，现在别碰）

```bash
sudo apt update && sudo apt install -y python3-venv python3-pip ffmpeg libgl1 libglib2.0-0
python3 -m venv .venv && source .venv/bin/activate
pip install -U pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install ultralytics openvino onnx onnxruntime psutil pandas matplotlib pyyaml
```

### 两个坑

- **不要用 `sudo` 跑 pip / python**，全部在 venv 里做
- `/mnt/f` 是跨文件系统访问，I/O 比 Windows 原生慢 3–5 倍。训练产物、数据集先放 WSL 家目录 `~`，最后再拷回 `/mnt/f`
