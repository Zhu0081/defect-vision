# 光源配对实验 · 操作单

> 目标：证明「侧光比顶光更容易检出划痕」，产出一张 2×2 表。
>
> 预计耗时：**准备 10 分钟 + 拍摄 40 分钟 + 入库 5 分钟**。
> 需要白天自然光吗？**不需要**。全程只开一盏台灯，所以阴天、晚上都能做。

---

## 为什么做这个

招聘 JD 里「**熟悉光源、相机、镜头选型**」出现频率很高，而你到现在
**只有侧光，没有对照组** —— 说过做过，但没有数字能证明。

这个实验只做一件事：**同一批纸、同一个模型、同一台相机，只换光源，看指标差多少。**

关键点：**不重新训练**。直接用现在的 `models/best.onnx` 去测。

原因是——如果重训，模型权重变了、数据划分变了，Δ 就没法归因到光源；
**只有「其他全不变，只换光」才能把差异归给光。**

## 一、准备（10 分钟）

### 1. 材料

| 东西 | 数量 | 说明 |
|---|---|---|
| 白纸（A4 或笔记本纸） | **8 张** | 编号 p025 – p032，**每张一个件号** |
| 黑笔 / 马克笔 | 1 支 | 马克笔更好，3 mm 宽 |
| 台灯 | 1 盏 | 宿舍台灯就行 |
| 深色布 / 黑衣服 | 1 块 | 垫在纸下面 |
| 手机 | 1 部 | 已经会用锁定曝光了 |

### 2. 8 张纸的分工

```
p025  空白（良品）
p026  空白（良品）
p027  空白（良品）
p028  空白（良品）

p029  划三道线（缺陷）
p030  划三道线（缺陷）
p031  划三道线（缺陷）
p032  划三道线（缺陷）
```

**缺陷纸的划线方式必须统一**：3 条，每条 4–6 cm 长，横竖都不限，但 4 张纸的
松紧程度要接近。**不要一张画得很夸张、一张很含蓄** —— 会让结论说不清。

> 写在纸背面用铅笔标一下件号，免得拍混。（别写在正面，会被拍到）

### 3. 建文件夹

```powershell
cd F:\defect-vision\data\phone_inbox
Remove-Item drop_side, drop_top -Recurse -Force -ErrorAction SilentlyContinue
1..8 | ForEach-Object {
  $n = "{0:000}" -f (24 + $_)
  New-Item -ItemType Directory -Force -Path "drop_side\p$n", "drop_top\p$n" | Out-Null
}
Get-ChildItem drop_side -Directory | ForEach-Object { $_.Name }
```

应该看到 `p025` 一直到 `p032`。

## 二、拍摄（40 分钟）

### 先定两件事，全程不许改

1. **手机位置固定**：架在书堆/杯子上，镜头朝下，纸放在桌面，**手机离纸 30–40 cm**
2. **相机参数锁定**：长按屏幕 1–2 秒出现 AE/AF 锁定黄条，之后**整个实验不再重锁**

> 参数一变，「光照差异」就混进了「曝光差异」，实验作废。

### 每张纸的拍摄流程（每张约 4 分钟）

**第一步：拍侧光 3 张**

侧光的做法：台灯放在纸的**侧面、高度和纸差不多**，光贴着纸面掠过去
（手在纸上方、靠近灯的一侧，能看到影子被拉得很长 = 角度对了）。

```
1. 纸放好，手机在正上方
2. 按快门 → 第 1 张
3. 纸平移 2 cm、转 10°，再按 → 第 2 张
4. 再挪一点、再转，按 → 第 3 张
```

**第二步：拍顶光 3 张（纸不动，只挪灯）**

顶光的做法：**不要把灯放到纸正上方**（会反光过曝）。
把灯**移到纸的另一侧偏上方**，让整张纸受光均匀、几乎看不到影子。

```
1. 灯挪位置，纸不动
2. 连拍 3 张，每张仍然平移 + 旋转一点点
```

### 顺序建议

**一张纸拍完两种光，再换下一张。** 不要「先拍完 8 张侧光，再拍 8 张顶光」——
中间灯动了、相机被碰了，所有纸就不可比了。

### 每张拍完立刻传

拍完一张纸的 6 张就导进对应文件夹：

```
侧光 3 张 → drop_side\p0XX\
顶光 3 张 → drop_top\p0XX\
```

> 传图用数据线（`DCIM\100APPLE`），别用微信 —— 微信会压缩。

### 中途自检（拍完第 1 张纸时看一眼）

打开第 1 张侧光图，确认：

- [ ] 纸面不是一片雪白（最亮处没糊）
- [ ] 纸的边缘清晰可见
- [ ] 划痕肉眼能看清

有问题先调灯，别急着往下拍。

## 三、入库（5 分钟）

```powershell
cd F:\defect-vision

# 侧光：8 张纸
foreach ($n in "025","026","027","028","029","030","031","032") {
  $lbl = if ([int]$n -ge 29) { "defect" } else { "good" }
  python src\data\ingest_phone.py --src "data\phone_inbox\drop_side\p$n" `
    --category card --part $n --light side --label $lbl --defect scratch
}

# 顶光：同 8 张纸，换 light
foreach ($n in "025","026","027","028","029","030","031","032") {
  $lbl = if ([int]$n -ge 29) { "defect" } else { "good" }
  python src\data\ingest_phone.py --src "data\phone_inbox\drop_top\p$n" `
    --category card --part $n --light top --label $lbl --defect scratch
}
```

> 良品传 `--label good` 时**不要**加 `--defect`。
> 如果脚本报错，先跑一次加 `--dry-run` 看看会做什么。

入库后应该是 **8 个新工件 / 48 张图**，每个工件 6 张（side 3 张 + top 3 张）。

检查：

```powershell
$r = Import-Csv data\captured\metadata.csv | Where-Object { [int]$_.part_id -ge 25 }
"新增 $($r.Count) 张"
$r | Group-Object part_id, light | ForEach-Object { "  $($_.Name)  $($_.Count) 张" }
```

期望：每个 `part_id + light` 组合正好 **3 张**，共 16 组。

## 五、怎么读这张表

| 结果 | 结论 | 面试怎么讲 |
|---|---|---|
| 侧光检出率明显更高（Δ ≥ 20 点） | **假设成立** | 「同一天、同一模型、同一批纸，只把灯从侧面移到顶上移动，检出率从 X% 掉到 Y%。所以划痕类缺陷必须用低角度掠射光。」 |
| 两者差不多（Δ < 5 点） | **划痕对这个模型来说足够明显**，光源不是瓶颈 | 「我以为光源很关键，实测差异不到 5 个点 —— 说明对我这个笔画宽度，成像质量已经不是瓶颈了。瓶颈在数据量。」 |
| 顶光反而更好 | 说明侧光角度没调对，或者顶光拍出了更强的对比度 | 诚实记录，回去看是哪几张判反了 |

**三种结论都能用。** 最怕的是没有对照组，只能说「我觉得侧光好」。

## 六、已知风险

| 风险 | 后果 | 预防 |
|---|---|---|
| 中途改了手机曝光 | Δ 混入曝光差异 | 全程不重锁 AE/AF |
| 两种光之间挪了手机 | Δ 混入位置差异 | 手机固定，**只挪灯** |
| 缺陷纸划线差异太大 | 说不出是「光的问题」还是「笔的问题」 | 4 张缺陷纸划线方式尽量一致 |
| 纸用了不同批次/亮度 | 同上 | 8 张纸用同一包 |
