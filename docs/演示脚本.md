# 3 分钟演示脚本

> 目标：让人在 3 分钟内相信三件事 —— **这套东西真能跑**、**他知道自己在做什么**、**他能说清边界**。

docker compose ps          # 两个 healthy 再往下

## 分镜

### 0:00 – 0:15 开场

把焦点放在浏览器，先说结论：

> "这是一个工业表面缺陷检测的端到端 Demo。用一台**没有独立显卡**的笔记本，从手机拍照开始，到标注、训练、导出 ONNX、FastAPI 服务、PostgreSQL 落库、网页演示，整条链路都是我做的。"

**不要**说"我是XX大学的学生，我来介绍一下我的项目"—— 直接进正题，15 秒内让人知道这是什么。

### 0:15 – 0:45 缺陷图

把 `card_p004_scratch_001.jpg` 拖进虚线框。

> "这是一张纸上的划痕。模型检出 5 处，最高置信度 0.66，耗时 180 毫秒。"

鼠标划过右边的表格：

> "每个缺陷都给出类别、置信度和归一化坐标——0 到 1，所以前端不用关心图片尺寸，换个分辨率也不会错位。"

### 0:45 – 1:05 良品图

拖 `card_p003_good_001.jpg`。

> "良品，0 处缺陷。这里看的是**过杀率**——工业上把良品判成废品的代价，比多看几眼高得多。"

### 1:05 – 1:35 阈值（切到标签 2）

> "我没有用默认的 0.25 置信度。我扫了 19 个阈值，出这条曲线。"
>
> "只看验证集是 100% 准确率、漏检 0、过杀 0 —— 漂亮得不像真的。但把测试集加进来，**漏检率卡在 20%，怎么调都下不去**。"
>
> 指右边直方图："原因在这：良品 15 张的最高分全部低于 0.08，划痕能到 0.96，分得开；但撕角只有 0.01 到 0.15，**和良品完全重叠**。这不是阈值没调好，是模型没见过撕角。"

### 1:35 – 2:10 工程决策（切到标签 3）

> "架构分三层：数据、模型、服务。两个决策我想展开说。"
>
> "第一，数据集是**按工件分组划分**的，不是按图片随机划分。同一个工件的几十张照片几乎一样，随机划分等于让模型背题——实测会让指标虚高 15 到 25 个点。"
>
> "第二，Docker 化之后我发现延迟从 200 毫秒涨到 1.4 秒。我没去调模型，而是把请求拆成解码、缩放、推理、落盘四段计时，定位到是 Windows 绑定挂载的写放大——写一张 2.8MB 的图花了 1219 毫秒。换成命名卷之后回到 180 毫秒。"

### 2:10 – 2:40 主动讲局限

拖 `card_p006_deform_001.jpg` 进去，屏幕显示 OK / 0 处。

> "这是撕角，模型完全没报出来。"
>
> "我很清楚这套东西的边界：42 张图、7 个工件，**换一个工件就失效**；只有一种光照；没做量化，没上边缘设备。"
>
> "要上产线，下一步是补到 200 张、20 个工件，加顶光和背光两组做光源对比，再叠一层无监督异常检测给未知缺陷兜底。"

**这一段最容易加分**：绝大多数学生会说"我的项目准确率 99%"，而你说"我知道它在哪会崩"。

### 2:40 – 3:00 收尾

切到标签 4（错题本）。

> "整个过程我记了 23 条踩坑记录，从 BOM 隐形字符到 PostgreSQL 时区。代码在本地仓库，可以现场跑。"

## 常见追问与回答

**Q：为什么用分割（seg）不用检测框（detect）？**
> 缺陷形状不规则，框会把大量背景算进去。分割能拿到实际轮廓，可以算面积、算长宽比——产线判定"划痕长度超过 2mm 才算不良"需要这个。

**Q：42 张也敢训？**
> 不敢，所以才有对照。test 上 mAP 是 0.0037，我把它写在 README 第一屏。这组数字的作用是证明：模型容量不是瓶颈，数据覆盖才是。

**Q：为什么不用更先进的模型？**
> YOLO11n 有 2.88M 参数，CPU 上 180 毫秒。换成 YOLO11x 确实精度更高,但没有独显训不动，而且产线的工控机就是 CPU。选型的第一约束是能落地。

**Q：为什么不用 PyTorch 直接推理，要转 ONNX？**
> 三个原因：一是部署时不带 torch，镜像从 2GB+ 降到 731MB；二是 ONNX Runtime 在 CPU 上比 PyTorch eager 快；三是导出时能把 NMS 固化进图里，线上不用再写一遍后处理。

**Q：这套和买现成的视觉软件比，优势在哪？**
> 现成的换工件要厂商来重新调参数，周期以周计。我这套换个工件只需要重拍、重标、重训，全流程脚本化的,一天能跑完。当然现成的在稳定性上比我强得多。

**Q：你觉得这个项目最大的问题是什么？**
> 数据。7 个工件、42 张图，连过拟合都不算——它只学到了特定纸面的外观。第二个问题是只有侧光一种光照，换个光源大概率崩。
